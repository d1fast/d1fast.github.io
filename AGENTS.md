# Работа с сайтом

- Язык общения и документации: русский. Писать просто, без длинных тире.
- Работать самостоятельно, без субагентов, пока владелец не попросит иначе.
- В коммитах использовать настроенные имя и почту владельца. Не добавлять префиксы и подписи инструментов.
- Пуш в main автоматически публикует сайт. Публикацию выполнять только по поручению владельца.
- Использовать существующую рабочую копию. Отдельное Git-дерево без просьбы владельца не создавать.
- Команды запуска и проверки описаны в docs/DEV.md. Тексты интерфейса находятся в src/i18n/ru.ts и en.ts.
- Главная без верхней шапки: работы слева, слоган с живой лентой по центру, знакомство и связь справа. Палитра голубовато-серая, винная и пыльно-розовая. Зелёный не использовать. Рассказ, кейсы и форма открываются в окне. Не возвращать пять разноцветных экранов и перехват прокрутки. Проверять телефон вместе с компьютером.
- Не помещать токен Telegram в клиентский код. PUBLIC_FORM_ENDPOINT является публичным адресом, а не секретом.
- Скриншоты проверок хранить в игнорируемой папке shots/. Медиа из public/work/ используются сайтом, удалять их только после проверки ссылок.
- Анимации всегда включены, в том числе при prefers-reduced-motion: reduce. Это явное пожелание владельца. Лента работает через Canvas 2D. Если Canvas недоступен, движется SVG-версия через CSS. Скрытая вкладка может приостанавливать отрисовку.
- Язык определяется по предпочтениям браузера, без переключателя и хранения выбора. Почту владельца не публиковать; связь и запросы по персональным данным доступны через форму.
