# Шрифты

Onest и Cormorant Garamond используются в портфолио. Golos Text и Playfair Display нужны исходникам демонстрационной кофейни и Telegram-бота.

Все шрифты распространяются под SIL Open Font License 1.1. Тексты лицензий находятся рядом с файлами.

- Onest: https://github.com/google/fonts/tree/main/ofl/onest
- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Golos Text: https://github.com/google/fonts/tree/main/ofl/golostext
- Playfair Display: https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Кириллическая и латинская части Cormorant Garamond Italic 600 получены через Google Fonts CSS API. Шрифты обслуживаются локально, обращений к Google Fonts при посещении портфолио нет.
