# Шрифты

Golos Text и Yeseva One используются в портфолио. Отдельные файлы Golos Text и Playfair Display нужны исходникам демонстрационной кофейни и Telegram-бота.

Все шрифты распространяются под SIL Open Font License 1.1. Тексты лицензий находятся рядом с файлами.

- Golos Text: https://github.com/google/fonts/tree/main/ofl/golostext
- Yeseva One: https://github.com/google/fonts/tree/main/ofl/yesevaone
- Playfair Display: https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Кириллические и латинские части Golos Text (400–700) и Yeseva One получены через Google Fonts CSS API. Шрифты обслуживаются локально, обращений к Google Fonts при посещении сайта нет.
